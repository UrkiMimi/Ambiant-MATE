# Ambiant-MATE-GTK4

This project is an attempt to port Ambiant-MATE to GTK4 (and hopefully XFWM). This project is very early in development and may not promise a working theme!

# About
This project is a fork of [Ambiant-MATE](https://github.com/lah7/Ambiant-MATE/tree/master) which is a fork of the [Ambiance/Radiance theme introduced in Ubuntu 10.04.](https://www.omgubuntu.co.uk/2010/02/new-theme-for-ubuntu-10-04-human-theme-dropped) This project aims to port Ambiant-MATE over to GTK4 as faithfully as possible.
